## Fixes

- Pasting or dropping an image into a note now leaves the cursor on a new line
  below the image and scrolls that line into view once the image finishes
  loading. Previously a tall image could push the cursor off screen, so you
  ended up typing somewhere you could not see
- If you click elsewhere in the note while an image is still being copied in,
  the image still lands where you added it and your cursor stays where you
  moved it
