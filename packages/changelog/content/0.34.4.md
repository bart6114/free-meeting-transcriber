## Fixes

- Closing a note that has no title and no typed text no longer discards it when
  it still holds attachments. Files you added to the note, and anything you
  dropped into the note's folder in your vault yourself, now count as content
  and keep the note around
- Housekeeping files the app manages itself (the recording, the transcript, and
  similar) still do not count, so genuinely empty notes are cleaned up on close
  exactly as before
