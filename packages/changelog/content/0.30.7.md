<banner title="The app is now called Loofah">
Same app, new name and new icon. Your notes, recordings, and settings stay
exactly where they are, and nothing needs to be moved or re-imported.
</banner>

## New

- The app is now called Loofah, with new artwork to match. You will see the
  new name and icon in your Applications folder, the Dock, the menu bar, and
  the About window. Everything carries over on first launch: your vault stays
  at the same location, your settings and window position come with you, and
  if you had "start at login" turned on it stays on under the new name. When
  you choose a location for a brand new vault, the folder the app suggests is
  now called "Loofah"
- Opening the app now shows a startup screen instead of a blank window while
  your vault is being read. It says what it is doing (scanning your notes,
  then indexing them, with a running count), so a large vault no longer looks
  like the app has frozen. If it is taking a while, a button appears to switch
  to a different vault folder, and if opening fails outright you get the error
  along with a "Try again" button
- For a vault kept in a cloud folder, that screen adds a hint (naming Google
  Drive when it recognizes it) that your provider may still be downloading
  files, and that Loofah will carry on by itself once the vault is there
- The command line tool is now called `loofah`, and its `meetings` commands
  are now `sessions`, as in `loofah sessions list`. The old `fmtr` command and
  the `meetings` name both still work, so existing scripts and agent setups
  keep running. Using `meetings` prints a short notice pointing you at the new
  name
- Notes you export to PDF now read "Exported from loofah.io" on the cover page

## Fixes

- The formatting toolbar that appears when you select text in a note no longer
  flashes in the wrong spot first. It used to show up in the corner of the
  window for a moment and then jump to your selection; now it fades in already
  in place, and it keeps up as you scroll or extend the selection
- Setup no longer asks for the macOS Accessibility permission, and the entry
  is gone from Settings. The only thing that used it was a small indicator for
  when Zoom was muted mid-recording, which has been removed, so the app was
  asking for access it no longer needs. Recording, transcription, and
  summaries are unaffected
