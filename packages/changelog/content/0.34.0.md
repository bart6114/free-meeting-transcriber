## New

- Every note now has an Attachments tab, reachable from the paperclip icon next
  to the note's other tabs. It lists every file attached to that note with its
  name, type, and size, and clicking a row opens the file in whichever app
  macOS normally uses for it
- Add files with the "Add attachments" button, or drop them anywhere in the
  tab. Files added this way live with the note in your vault, so they travel
  with it
- "Show in Finder" opens that note's attachments folder directly. If you add,
  rename, or delete files there, the list catches up as soon as you switch back
  to Loofah
- Removing an attachment asks for confirmation first, explains that the file
  moves to the vault Trash, and warns that links to it in notes or summaries
  may stop working
- Files you drop into a note now appear right away as a placeholder that shows
  the name and a copy progress state, so long copies no longer look like
  nothing happened. If a copy fails, the placeholder offers Retry and Remove
  instead of disappearing silently

## Fixes

- Dropped files are now copied straight from their location on disk instead of
  being loaded into memory first. Dropping large files, or many files at once,
  is noticeably lighter on the app
- An interrupted copy (running out of disk space, for example) no longer leaves
  a half-written file sitting in your vault. Attachments appear only once they
  are complete, and a file dropped twice still gets a numbered name like "file
  1.txt" rather than overwriting the first one
- The import audio dialog uses the same drop handling. Dropping a folder still
  picks up the audio files inside it, now listed in alphabetical order
- In the Attachments tab, the drop highlight now covers the whole pane,
  including the area around the note title. Previously the top of the tab was
  not a valid drop target, so a drop aimed there did nothing
