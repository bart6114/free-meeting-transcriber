## Fixes

- The macOS download is now notarized by Apple, and the approval is stapled into
  the disk image itself. Opening the downloaded DMG no longer trips the "Apple
  cannot check it for malicious software" warning, and the check passes even
  when you are offline. Previously only the app inside the image carried a
  signature, so the image itself was treated as unverified

## Notes

- Nothing else in the app changed in this version. The most recent behaviour
  changes are still the ones from 0.32.6: dropping several files into a note at
  once, drops registering anywhere in the note area rather than only on a line
  of text, and a clearer message about what each dropped file will become
