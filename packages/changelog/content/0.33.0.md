## Highlight

- A large amount of old, dead code was removed or refactored across the desktop
  app and its build system. This is an internal cleanup: notes, recordings,
  transcripts, settings, imports, and the rest of the app should work exactly as
  before, on a smaller and easier-to-maintain foundation

## Quality

- The cleanup was checked with the full frontend, Rust, CLI, documentation, and
  workflow test suites, a staging desktop build, and a seeded-vault app run
- We do not expect any visible changes. If something unexpected does appear,
  please [file an issue](https://github.com/bart6114/loofah/issues) so we can
  investigate it
