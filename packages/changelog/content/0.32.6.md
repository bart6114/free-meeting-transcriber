---

## New

- You can drop more than one file at a time. Each file is inserted where you
  dropped it, in the order you dropped them, instead of everything piling up at
  a single point in reverse
- The drop overlay now says what is about to happen before you let go: audio
  gets uploaded and transcribed, images land inline, and anything else is added
  as an attachment. Drag a mix of audio and other files and it tells you both
  will happen

## Fixes

- Dropping a file now registers anywhere in the note area, not only when the
  file lands exactly on a line of text. Empty space below the last paragraph,
  the margins, and the area around the title all accept a drop
- Files can be dropped onto AI-generated documents the same way as onto your own
  notes. The drop highlight used to only show up for audio there, and other
  files were easy to miss
- If an attachment fails to save, the app now says so by name instead of
  quietly dropping it. The same goes for a drag the app cannot read at all,
  which used to look like nothing happened
- Switching notes or tabs in the middle of a drag no longer leaves the drop
  highlight stuck on screen
