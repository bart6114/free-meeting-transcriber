---
title: "MCP for agents"
description: "Connect an MCP client to local Free Meeting Transcriber meeting context over stdio."
---

The MCP server runs inside the `fmtr` executable and communicates over standard input and output. It does not open a port or send meeting data to a hosted service.

## Configure a client

Use this generic MCP configuration:

```json
{
  "mcpServers": {
    "fmtr": {
      "command": "fmtr",
      "args": ["mcp"]
    }
  }
}
```

If `fmtr` is not on the client's `PATH`, use the executable's absolute path as `command`. Restart the client after changing its configuration.

For a custom vault path:

```json
{
  "mcpServers": {
    "fmtr": {
      "command": "fmtr",
      "args": ["--vault-path", "/path/to/vault", "mcp"]
    }
  }
}
```

## Use tools deliberately

Start with `list_meetings`, then pass the returned `id` to `get_meeting`. Only call `get_meeting_transcript` if notes and summaries do not contain the required evidence.

`get_meeting_transcript` returns the whole meeting as `[HH:MM:SS] Speaker: ...` lines, so one call is enough.

See the [MCP reference](/reference/mcp) for exact parameters and resources.
