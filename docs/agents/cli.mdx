---
title: "CLI for agents"
description: "Use structured Free Meeting Transcriber CLI output as an agent-friendly MCP fallback."
---

Pass the global `--json` flag when an agent consumes CLI output.

Every successful JSON response contains `schema_version`, `command`, `data`, and optional `pagination`. Read meeting results from `data` and continue from `pagination.next_offset` only when needed.

## Resolve meeting context

```bash
fmtr --json meetings list --query "weekly planning" --limit 10
fmtr --json meetings get MEETING_ID
```

Search is case-insensitive across meeting titles and IDs. If several results match, ask the user which meeting they mean.

## Read the smallest useful surface

```bash
fmtr --json meetings note MEETING_ID --kind note
fmtr --json meetings note MEETING_ID --kind summary
```

Use `meetings get` when action items matter. Use `meetings note` when note content alone is enough.

## Transcripts

```bash
fmtr --json meetings transcript MEETING_ID --limit 200 --offset 0
```

Transcript limits are measured in words. The default is 200 and the maximum is 500. Continue from `pagination.next_offset` only when the next page is necessary.

## Diagnose setup

```bash
fmtr --json doctor
```

The report includes the CLI version, an overall `ready` flag, and vault health: the resolved vault path, whether it exists and is a directory, and the session count.
The command exits with status 1 when `ready` is false while preserving the diagnostic report on standard output.

When the vault lives somewhere non-standard, point the CLI at it with the global `--vault-path DIR` flag or the `FMTR_VAULT_PATH` environment variable.

## Exports

Only export a complete meeting when the user explicitly requests a file:

```bash
fmtr meetings export MEETING_ID --format markdown --output meeting.md
fmtr meetings export MEETING_ID --format json --output meeting.json
```

Export refuses to replace an existing file. Use `--force` only after the user explicitly approves overwriting that exact path.

See the [CLI reference](/reference/cli) for every option.
