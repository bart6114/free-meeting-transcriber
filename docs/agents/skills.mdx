The public Free Meeting Transcriber skill gives agents one transport-agnostic workflow:

1. Prefer connected Free Meeting Transcriber MCP tools.
2. Fall back to `fmtr --json` when MCP is unavailable.
3. Resolve meeting IDs from search results.
4. Fetch meeting detail before transcript text.
5. Keep transcript reads bounded and never crawl or modify the vault files directly.

## Canonical source

- Repository package: [`skills/fmtr`](https://github.com/bart6114/free-meeting-transcriber/tree/main/skills/fmtr)

The repository package includes concise references for setup, CLI commands, MCP tools, and errors.

## Install in an agent

For a filesystem-based agent, copy the complete `skills/fmtr` directory into that agent's skills directory. Keep the directory name `fmtr` so relative reference links continue to work.

<Note>
  Agent skill locations and installer commands vary by client. Follow your agent's skill installation instructions rather than copying only `SKILL.md`.
</Note>

The contributor skills under `.agents/skills` are internal repository workflows. They are not part of the public Free Meeting Transcriber skill.
