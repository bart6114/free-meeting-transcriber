Free Meeting Transcriber uses two model settings:

- **Transcription** turns meeting audio into a transcript. It always runs on-device.
- **Intelligence** creates summaries and note titles. Choose a local server or a provider with your own API key.

Open **Settings → Transcription** or **Settings → Intelligence** to choose a model.

## Choose a setup

Models labeled **Live** show text during the meeting; live transcription is currently English-only, and other languages are transcribed after the recording. Models labeled **After recording** always transcribe after you stop.

To keep transcription and summaries on your computer, follow [Use Free Meeting Transcriber offline](/offline).

## LM Studio

1. Install [LM Studio](https://lmstudio.ai/download) and download a model.
2. Start its local server on port `1234` and enable CORS.
3. In Free Meeting Transcriber, open **Settings → Intelligence → Configure Providers → LM Studio**.
4. Select the LM Studio model under **Model being used**.

## Ollama

1. Install [Ollama](https://ollama.com/download).
2. Start it and pull a model:

   ```bash
   ollama serve
   ollama pull llama3.2
   ```

3. In Free Meeting Transcriber, open **Settings → Intelligence → Configure Providers → Ollama**.
4. Select the Ollama model under **Model being used**.

## What leaves your computer

Your app data remains local. Local transcription and local Intelligence providers process content on your computer. If you select a remote API-key provider, Free Meeting Transcriber sends the text needed for that request to the selected provider.

See [Data, privacy, and retention](/data-and-privacy) for a feature-by-feature explanation.
