description: "Quick answers and links to the relevant guide."
---

<CardGroup cols={2}>
  <Card title="Does it join the call?" icon="video-slash" href="/meetings">
    No. It records microphone and system audio on your Mac.
  </Card>
  <Card title="Can I use it offline?" icon="wifi-slash" href="/offline">
    Yes. Download the transcription model first, and use LM Studio or Ollama for local summaries.
  </Card>
  <Card title="Where are my meetings stored?" icon="hard-drive" href="/data-and-privacy">
    In files inside your local vault. There is no cloud backend.
  </Card>
  <Card title="Can I import an old recording?" icon="file-arrow-up" href="/import-recordings">
    Yes. Import common audio formats, SRT, or VTT.
  </Card>
  <Card title="Can recording start automatically?" icon="clock" href="/automatic-capture">
    No. The app can remind you when it detects microphone use, but you decide when recording starts.
  </Card>
  <Card title="Can I change the summary format?" icon="wand-magic-sparkles" href="/customize-summaries">
    Yes. Use a template or edit the prompt used by Auto.
  </Card>
  <Card title="What about multilingual meetings?" icon="language" href="/languages">
    Add the spoken languages in Settings. Model support determines whether transcription can run live.
  </Card>
  <Card title="How do I export a meeting?" icon="file-export" href="/notes#export-a-meeting">
    Export the memo, summary, transcript, or any combination of them.
  </Card>
</CardGroup>

If the app is not behaving as described, try [Troubleshooting](/troubleshooting). If that does not help, [open a GitHub issue](https://github.com/bart6114/free-meeting-transcriber/issues).
