## Audio is missing

Open **Settings → Permissions** and confirm:

- **Microphone** is allowed so Free Meeting Transcriber can hear you.
- **System Audio** is allowed so Free Meeting Transcriber can hear the other people on the call.

If a permission is denied, open it in macOS Settings from the permission row, then restart Free Meeting Transcriber.

## The transcript is not live

Open **Settings → Transcription** and check the selected model. **Live** models transcribe during the meeting. **After recording** models wait until you stop.

If transcription fails, confirm the model is downloaded and supports your spoken languages. See [Use multiple languages](/languages) for what each model supports.

## No summary appears

A summary needs an Intelligence model. Open **Settings → Intelligence**, then select a local model or configure a provider with your own API key.

For LM Studio and Ollama, confirm the local server is running. See [Transcription and AI](/ai-setup).

## A recording disappeared

Open **Settings → App → Meetings** and check **Audio file retention**. Free Meeting Transcriber can delete audio immediately or after a selected period while keeping the note and transcript.

See [Data, privacy, and retention](/data-and-privacy#choose-how-long-audio-is-kept) for every retention option.

## An imported file does nothing

Audio imports accept WAV, MP3, OGG, MP4, M4A, FLAC, WebM, and AAC. Transcript imports accept SRT and VTT.

For audio, confirm that a Transcription model is selected and that a local provider is running. See [Import audio or a transcript](/import-recordings).
